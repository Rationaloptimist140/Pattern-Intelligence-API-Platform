# Pattern-Intelligence-API-Platform

Pattern Detector API — small, fast API to detect recurring patterns in time series and signal data.

Features
- REST API for pattern detection
- Example requests and usage
- Lightweight and easy to deploy

Quickstart (local)
1. Clone the repo:
   git clone https://github.com/Rationaloptimist140/Pattern-Intelligence-API-Platform.git
   cd Pattern-Intelligence-API-Platform
2. Install dependencies (if applicable):
   npm install
3. Run the server:
   npm start

Example usage
- POST /detect with JSON payload {"series": [1,2,3,4,5]} returns detected patterns and metadata.
